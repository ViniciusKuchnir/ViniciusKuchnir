## ⭐ Featured Projects

### 🚦 Speed Violation Service — Java Backend API

Backend service responsible for evaluating vehicle speed readings, applying
tolerance rules and identifying traffic violations.

#### Engineering Highlights

- Java 21 and Spring Boot 3
- Versioned REST API
- Jakarta Bean Validation
- Custom validation rules
- Business-rule isolation
- Standardized exception handling
- Thread-safe in-memory persistence
- Repository abstraction
- Immutable models with Records
- Unit and integration tests
- Automated coverage verification with JaCoCo
- Swagger / OpenAPI documentation
- Docker multi-stage build
- GitHub Actions CI pipeline
- Health monitoring with Spring Boot Actuator
- Containerized cloud deployment

#### Technologies

`Java 21` · `Spring Boot 3` · `Maven` · `JUnit 5` · `MockMvc` ·
`AssertJ` · `JaCoCo` · `OpenAPI` · `Docker` · `GitHub Actions`

#### Engineering Flow

```text

     │
     ▼

     │
     ▼

     │
     ▼
Persistence Abstraction
     │
     ▼

     │
     ▼

     │
     ▼
Continuous Integration
     │
     ▼
Deployment
```

The project also led to deeper exploration of topics such as
**idempotency, load testing and CQRS trade-offs**, considering architectural
changes only when justified by actual system behavior and measurable needs.
